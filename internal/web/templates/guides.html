{{/* Install guides. The section for the visitor's platform (.OS) opens first. Sources and verification status are listed in PLAN.md, milestone 6. */}} {{define "guides"}}
Windows
  1. Download the .pfx file (or the identical .p12) and open it. The Certificate Import Wizard starts.
  2. Leave Store Location as Current User and continue.
  3. Enter the passphrase that was shown when you created the certificate.
  4. Let Windows choose the certificate store, then finish.

Edge and Chrome use certificates from this store. When a site asks, choose this certificate. For Firefox, see below.

macOS

Recommended: on the Mac, use Add Apple device. The Mac creates a key that cannot be exported.

  1. Download the profile.
  2. Choose Apple menu → System Settings, click General, then Device Management. You may need to scroll down.
  3. In the Downloaded section, double-click the profile, then click Install.

Safari and Chrome then offer the certificate when a site asks. You can also open a .p12 file to add it to your login keychain.

iPhone and iPad
  1. Open AuthStep in Safari on the iPhone or iPad. From a computer, use Set up another device and scan the QR code.
  2. Tap Add Apple device and download the profile.
  3. Within 8 minutes, open Settings, tap Profile Downloaded, then tap Install in the upper-right corner and follow the steps. iOS deletes a downloaded profile that is not installed in time.

If Stolen Device Protection is on and you are not in a familiar location, turn it off before you install the profile and turn it on again afterwards. Installed profiles are listed in Settings → General → VPN & Device Management.

Apple TV
  1. On a phone or computer, open Add Apple TV, name the Apple TV and create the link.
  2. On the Apple TV, open Settings → General → Privacy & Security. Highlight Share Apple TV Analytics and press Play/Pause on the remote.
  3. Select Add Profile and type the link within 10 minutes, then install the profile.

The Add Profile menu is hidden and not documented by Apple, so it can change in a tvOS update. Apps on the Apple TV decide whether they use the certificate.

Android
  1. On the phone, open AuthStep in Chrome, create a new certificate and download the .p12 file. From a computer, use Set up another device and scan the QR code.
  2. Open Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate.
  3. Choose the user certificate for apps and VPN, not the CA or Wi-Fi certificate.
  4. Select the downloaded file, enter the passphrase and give the certificate a name.

These names are from Pixel phones on Android 14 and later. Other phone makers use similar but different menu names.

Linux

Chrome and Chromium: open chrome://settings/certificates, click Manage Certificates and import the .p12 file. Or use the command line (package libnss3-tools or nss-tools):

pk12util -d sql:$HOME/.local/share/pki/nssdb -i certificate.p12

If you have an older $HOME/.pki/nssdb folder, Chrome uses that one instead.

Firefox (any system)
  1. Open Settings → Privacy & Security and go to Certificates.
  2. Click View Certificates, select the Your Certificates tab and click Import.
  3. Choose the .p12 file and enter the passphrase.
Command-line tools 
curl --cert-type P12 --cert certificate.p12:PASSPHRASE https://service.example.com/

Tools that need PEM files can use the certificate .pem and private key .pem downloads.
